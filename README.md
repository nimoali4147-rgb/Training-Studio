# 🏋️ Training Studio

A modern and responsive fitness training studio website built with **HTML** and **Tailwind CSS**.

The website is designed for a professional gym or fitness studio, with a dark and energetic visual style, smooth navigation, training classes, trainers, schedules, and membership-focused sections.


## 🌐 Live Demo

🔗 [View Training Studio Website](http://127.0.0.1:5500/index.html)


## ✨ Features

- 🏠 Modern hero/home section
- 🎥 Full-screen background video
- 🏋️ Training and fitness classes
- 👨‍🏫 Trainer section
- 📅 Training schedule
- 💪 Fitness programs
- 📊 Studio statistics
- 📱 Fully responsive design
- 🎨 Modern dark and purple color theme
- 🔗 Smooth navigation between sections
- 📞 Contact section
- 📱 Mobile-friendly layout


## 🛠️ Technologies Used

### Frontend

- **HTML5**
- **Tailwind CSS**
- **CSS**

### Design

- Responsive layout
- Tailwind utility classes
- Background video
- Gradient overlays
- Hover effects
- Modern typography
- Mobile-first design
